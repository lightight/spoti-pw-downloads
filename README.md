# spoti.pw Updates

Add this source once in **Feather → Sources → +**:

https://raw.githubusercontent.com/lightight/spoti-pw-downloads/main/source.json

Download spoti.pw from this source, then sign and install it. Later builds appear after refreshing
Sources or checking Library for updates. Each source version includes a build timestamp and hash,
so fixes to the same mod/Spotify version can still be detected. Keep the same signing identity and
bundle identifier when replacing an existing installation.

Direct latest IPA (for manual URL import): https://github.com/lightight/spoti-pw-downloads/releases/latest/download/spoti.pw.ipa

IPAs retain their original bundle identifier and are ready to sign with your own certificate.
Native UI requires iOS 16.1+, and Redesigned UI requires iOS 26+.
